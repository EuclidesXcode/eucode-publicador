Política de Privacidade

Publicador Eucode — atualizada em 3 de novembro de 2026

Quem usa

O Publicador Eucode é uma ferramenta de uso pessoal. O único usuário é o próprio criador do canal Eucode, que autoriza o acesso às suas próprias contas.

Quais dados são acessados

  • YouTube (Google): permissão para enviar vídeos (youtube.upload) e ler informações básicas do próprio canal (youtube.readonly), usadas para conferir se o envio foi concluído.
  • TikTok: informações básicas do perfil e envio de vídeos para a caixa de entrada do próprio criador.
  • Facebook (Meta): publicação de vídeos na Página do próprio criador.

Não são acessados dados de outras pessoas, comentários, mensagens, contatos, e-mails ou informações de pagamento.

Como os dados são guardados

Os tokens de acesso ficam salvos apenas no computador do criador, numa pasta local que não é enviada para nenhum servidor. Nenhum dado é vendido, compartilhado com terceiros ou usado para publicidade.

Uso dos dados do Google

O uso e a transferência de informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado. A ferramenta usa os Serviços de API do YouTube e segue os Termos de Serviço do YouTube e a Política de Privacidade do Google.

Como revogar o acesso

O acesso pode ser removido a qualquer momento em myaccount.google.com/permissions (Google/YouTube), nas configurações de apps do TikTok e em Configurações > Integrações comerciais do Facebook. Também basta apagar a pasta local de credenciais.
